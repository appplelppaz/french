# フランス語文法テキスト

日本語話者のための、大学レベルのフランス語文法テキストです。元の教科書の全32項目に枝番の章を加えた全41章。

紙の教科書にできない3つのことをやります。

- **フランス語はどこをクリックしても発音が鳴る** — 本文中の赤い語句、例文、活用表のすべてのセル
- **動詞の活用を反復練習できる** — 間違えた項目を記録して優先的に出題するドリル
- **分からないところをその場で質問できる** — Gemini API と連携（任意）

依存パッケージはありません。`npm install` も不要で、`index.html` をブラウザで開けば動きます。

---

## 使い方

### そのまま開く

```
index.html をブラウザで開く
```

ローカルのファイルとして開いても、Web サーバー経由でも、同じように動作します。

### 1ファイル完結版を使う

`dist/french-textbook.html` は、CSS・JavaScript・全41章を1つに埋め込んだファイルです。
**このファイル1つをダウンロードすれば、オフラインでも全機能が使えます。** メールに添付しても、USB に入れても動きます。

再生成するには：

```
node build.js
```

## 機能

### 音声

本文中の赤いフランス語、例文ブロック、活用表のセルは、**クリックすると発音が鳴ります**。例文ブロックと語彙リストには「通して聞く」ボタンがあります。

ブラウザ内蔵の読み上げ機能（Web Speech API）を使っているので、音声ファイルのダウンロードは不要です。読み上げの声と速さは設定画面で変えられます（学習には「ゆっくり」が有効です）。

**フランス語の音声が入っていない端末では**、画面上部に案内が出ます。次の手順で追加できます。

| OS | 手順 |
|---|---|
| Windows | 設定 → 時刻と言語 → 言語と地域 → 言語の追加 →「フランス語」→ 音声認識・音声合成にチェック |
| macOS | システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 「フランス語」を追加 |
| iPhone / iPad | 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → フランス語 |
| Android | 設定 → システム → 言語と入力 → テキスト読み上げ → 言語データのインストール |

音声がなくても、本文・活用表・ドリル・AI 機能はすべて使えます。

### 活用表

- どのセルもクリックで発音
- **「語幹と語尾」** を押すと色分けされ、活用の仕組みが見えます
- **「同じ音」** を押すと、綴りが違うのに発音が同じセルに印が付きます
  （`chante / chantes / chante / chantent` は4つとも同じ音、というのが最も気づきにくい難所です）

対応する時制：直説法の現在・複合過去・半過去・大過去・単純未来・前未来・単純過去、条件法の現在・過去、接続法の現在・過去、命令法。代名動詞（`se lever` など）にも対応しています。

### 活用ドリル

サイドバーの「活用ドリル」から。動詞と時制を選んで練習します。

- 入力式と4択式を切り替えられます
- アクセント記号は入力補助ボタンで打てます。記号を落とすと「惜しい」と判定されます
- **間違えた項目は記録され、次回以降くり返し出題されます**
- 苦手な項目だけをまとめて練習できます

章の中にも、その章に対応したドリルが埋め込まれています。

### AI 機能（任意）

Gemini API と連携すると、次の4つが使えます。

| 機能 | 場所 |
|---|---|
| **文法質問チャット** | 右上の星印のボタン。今読んでいる章の本文を踏まえて答えます |
| **例文の自動生成** | 各章の末尾。テーマ・難易度・本数を指定できます |
| **作文添削** | 各章の末尾。書いた仏文を、その章の文法に照らして直します |
| **活用ドリルの解説** | ドリルで間違えたとき「なぜこの形になるの？」 |

生成された例文の中のフランス語も、**クリックすれば発音が鳴ります**。気に入った例文は「マイ例文」に保存できます。

**API キーの設定**

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを作成します（無料枠があります）
2. サイトの設定画面でキーを貼り付けて「保存」

キーは**このブラウザの localStorage にのみ保存されます**。リポジトリにも、他のどこにも送信されません。通信先は Google の API（`generativelanguage.googleapis.com`）だけです。

- 共有のパソコンで使った場合は、終わったら設定画面の「キーを削除」を押してください
- 公開サイトで使う場合は、Google AI Studio 側でキーに **HTTP リファラ制限**をかけておくと安全です
- キーを設定しなくても、教材本体（本文・音声・活用表・ドリル）はすべて動きます

### その他

- **全文検索** — 右上の検索欄、または `/` キー
- **学習の進捗** — 各章末の「この章を読了にする」でチェック。サイドバーに反映されます
- **テーマ** — 既定は「端末の設定に合わせる」。明るい環境では紙色のライト、暗い環境では低グレアのダークに切り替わります。設定画面で固定もできます
- **文字サイズ** — 設定画面で4段階（小／標準／大／特大）。読み物の列だけが拡縮します
- **章内目次** — 右側。長い章の中を移動できます
- **iPad / スマートフォン対応** — タップ標的は 44pt 以上。iPad では Apple Pencil の Scribble でドリルに直接手書き入力でき、**手書き練習パッド**（お手本をなぞって綴りを練習）も使えます

学習データ（進捗・ドリルの成績・マイ例文・設定）は、すべてブラウザの localStorage に保存されます。サーバーには何も送信されません。

## デザイン

**長時間読むための教科書**として設計しています。

- **既定は紙色のライト** — 地は純白（#fff）ではなく書籍用紙に近い #f6f3ec、文字は純黒ではなく墨色の #26241f。グレアとコントラスト過剰を避けています
- **ダークは低グレア版** — 端末がダークモードのとき自動で切り替わります。地は真黒にせず #15151a、文字は #d2d2d9。赤アクセントも彩度を落としてあります
- **本文 17px / 1行 40em** — 書籍の組版に寄せた行長と行間
- **注記は左の縦線1本** — 5種類の注記ボックスに地色を持たせず、線とラベルの色だけで区別します
- **表は横罫線のみ** — 外枠と塗りを排し、視覚的なノイズを減らしています
- **アイコンは単色 SVG** — 絵文字は使いません。端末による見た目のばらつきがなく、テーマの色を継ぎます

活用表の色分け（**語幹＝深緑 / 語尾＝臙脂**）は、両テーマで判別できる濃度に調整してあります。

## GitHub Pages で公開する

このリポジトリはルートに `index.html` があるので、追加の設定は要りません。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」に
3. **Branch** を `main` / `(root)` に設定して Save

数分後に `https://<ユーザー名>.github.io/french/` で公開されます。

ビルド工程がないので GitHub Actions は不要です。`.nojekyll` を置いてあるため、Jekyll による処理も走りません。

### テスト


**教材である以上、活用形の誤りは致命的**なので、規則動詞・綴りが変わる動詞・不規則動詞・全複合時制・代名動詞・非人称動詞の代表例をテストで固定しています。

### 章の書き方

各章は `content/chNN.js` に、Markdown のサブセット＋独自記法で書きます。

````
FR.chapter({
  id: 'ch08', no: '8',
  title: '—er 動詞',
  sub: '「歌い」、「踊り」、「愛する」ために',
  body: `
## 見出し

[[Je t'aime.|ジュ・テーム|愛してる。]]     クリックで発音するチップ

:::ex 例文ブロック
Je chante. | ジュ・シャント | 私は歌う。
:::

:::note ポイント / :::warn 要注意 / :::adv 発展 / :::deep 詳しく

:::conj chanter présent,futur      活用表
:::drill chanter,finir présent     活用ドリル
:::vmap chanter                    活用の全体図


:::vocab この章の語彙
mot | 品詞 | 意味
:::

:::ai-gen 例文生成・作文添削のボタン
`
});
````

書いたら `node test/content.test.js` で検査します。ブロックの閉じ忘れ、存在しない動詞や時制の指定、表の列ずれ、分量の不足などを検出します。

原稿はテンプレートリテラルの中に入るので、**バッククォートと `${` は使えません**（`build.js` が混入を検査します）。

### 設計上の注意

- 章は `<script>` タグで読み込みます。`fetch` を使うと `file://` で開いたときに CORS で失敗するためです
- 本文の描画はすべて DOM API で行い、文字列を `innerHTML` に流し込む箇所はありません。AI の生成テキストも同じ経路を通ります
- 活用エンジンは全時制をベタ書きせず、「語幹 × 語尾」と語幹どうしの依存関係から導出します（第13章で説明している構造そのものです）
- 色はすべて CSS カスタムプロパティ経由です。`:root` が紙のライト、`[data-theme="dark"]` と `prefers-color-scheme: dark` がダーク。個別の要素に色を直書きしません
- タッチ対応は `@media (pointer: coarse)` と `@media (hover: none)` で分岐します。hover でしか出ない UI を作らないことが原則です
- 手書きパッドは Pointer Events のみで実装しています（筆圧は `e.pressure`、Pencil の高頻度入力は `getCoalescedEvents()` で拾います）
